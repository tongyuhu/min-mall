# 工程与环境

七个 Maven 子模块最终组成一个应用，只有 mall-app 负责启动和打包。业务模块之间通过应用服务调用，共享同一个数据源和事务管理器。

MySQL 与 Redis 由 Compose 启动；容器化应用是可选 profile。所有端口默认绑定本机，不修改系统中已有的服务。开发密码保存在未跟踪的 .env，Java 本地进程须显式导入环境变量。

源码准备不等于运行验证。2026-11-11 用户明确授权后，项目已通过完整构建、59 个测试、完整 HTTP 演示与进程重启恢复验证，具体证据见验收记录。测试使用独立容器与随机端口，不连接开发库。

本轮验证中，UTC 时间曾被 JDBC Timestamp 按本机时区写成晚 8 小时，并出现微秒四舍五入。统一改为 UTC LocalDateTime、写入前截断到微秒后通过了时间往返、优惠券、到期关闭和轨迹去重用例。学习时应同时理解 Java 时间类型、JDBC 类型及数据库字段语义，不能只在 JSON 配置里指定 UTC。
