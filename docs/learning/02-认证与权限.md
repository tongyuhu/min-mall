# 认证与权限

密码使用 BCrypt，原文不写数据库和日志。登录返回随机令牌，Redis 保存令牌摘要及固定两小时会话。请求携带 Authorization: Bearer 令牌，不使用 Cookie 或服务器 HttpSession，因此关闭浏览器会话型 CSRF；默认不开放跨域。

每次请求查询账户当前 enabled、auth_version 和管理员权限。修改密码、禁用账户会递增版本，旧令牌即便还在 Redis 也不能继续使用。Redis 不可用时返回503，不放行请求。管理员和买家账户分离。

登录和注册按账号与真实来源IP限流，不信任客户端伪造的转发头。角色权限变化无需等待令牌过期。
