# 商城前端实施计划

> 执行技能：superpowers:executing-plans。在当前会话顺序实现；用户已授权推荐方案直接执行，不再逐步等待确认。

**目标：** 完成对接真实后端的响应式买家商城和管理后台。
**架构：** 当前 checkout 内新增 frontend；两套页面、独立会话、共享请求与类型；最小增量补充后端读取和本地模拟接口。
**技术栈：** Vue 3、TypeScript、Vite、Vue Router、Element Plus、Vitest、Playwright。
**设计：** docs/superpowers/specs/2026-11-12-mall-web-design.md

## 全局约束

中文文案；ID 字符串；金额整数分；保留现有直接 DTO；开发密钥不得进入前端；仅本机开发服务；不自动提交推送。复用当前 feat/mini-mall checkout，避免已有运行服务与路径脱节。
