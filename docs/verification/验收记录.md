1. 沿用已批准的当前 checkout，切到功能分支，不另建 worktree。代价是当前目录包含全部实现改动；未合并或推送。
2. 先写测试源码，按用户约束不编译运行。代价是不能证明类型正确、启动成功、事务语义和功能通过，后续必须实际验证。
3. 技能任务脚本不识别中文“任务”标题，使用本地提取脚本与进度记录。代价是需要人工核对任务编号，已用提交序列对照。
4. 普通实体使用 MyBatis-Plus，复杂锁与原子 SQL 经公共 Database/SqlMapper 预编译执行，SQL 保留在所属模块。代价是必须坚持代码内 SQL 和参数绑定，禁止客户端 SQL；不能仅靠 import 检查证明所有 SQL 所有权。
5. 最终阶段新增 V14，记录本地种子版本并为人工重试增加独立等待起点。代价是多一个迁移；保留旧迁移不改写，重试不覆盖原创建时间。
6. 闭环自动化拆为业务服务集成用例与完整 HTTP 演示脚本，worker 恢复用对象重建验证。代价是进程终止后的真实重启恢复仍需运行阶段补验，不能将其宣传为已验证。
