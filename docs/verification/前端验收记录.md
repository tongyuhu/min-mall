## 实施决定与边界

- 用户已授权直接采用推荐方案，因此不重复等待设计/计划确认；设计和计划仍落盘，供学习和复核。
- 复用当前 `feat/mini-mall` checkout，避免已有本地服务与路径脱节；改动保留待用户提交。
- 使用一个前端工程中的两套页面和少量组合函数状态，暂不引入 Pinia；若以后需要跨页缓存，可在现有 shared 边界接入。
- 模拟操作仅面向本地学习，不替代真实支付/物流接入；没有文件上传或生产上线。
- 浏览器验收创建了测试买家、订单及后台草稿商品。商品 CRUD 用例在结束时将验收商品下架，不删除用户原有数据。
